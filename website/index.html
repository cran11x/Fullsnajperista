Quick Start

1

Download & Install

Download the application for your platform and install it.

2

Configure Settings

Open the Settings tab and configure your wallet private key, Helius API key, and trading parameters.

3

Set Filters

Configure your filters (market cap, socials, DAS verification) in the Settings tab.

4

Start Sniping

Click "Start Bot" and watch the dashboard for detected tokens and successful buys.

Requirements

Helius API Key

Required for RPC and WebSocket connections. Get one at helius.dev

Solana Wallet

Private key for your Solana wallet with SOL for transactions

System

Windows 10+ or macOS 10.13+ with stable internet connection
